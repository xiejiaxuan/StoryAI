## 三、文笔约束

### 3.1 通用规则（所有小说必须遵守）

- 简洁克制——不用华丽辞藻堆砌
- 画面感优先——每段描写都能在脑中形成画面
- 留白美学——情感高潮处不写满
- 沉默的力量——"不说话"比台词更有张力
- 对话必须有潜台词——说的不是真正想说的
- 每个角色开口就能被认出来
- 第三人称深度视角——叙述句就是主角的所见所判所想

### 3.2 类型特定风格

{{如果是仙侠}}
- 古风点缀适度——文言句式 + 诗句引用，但不过量
- 战斗场景：动作具体、感官丰富、慢镜头处理关键时刻
- 修炼描写：不堆术语，用身体感受代替抽象概念
{{如果是都市}}
- 对话口语化、生活化
- 禁止文艺腔，直接有力的短句
{{其他类型类推}}

## 四、节奏约束

### 4.1 卷级节奏

- 每卷至少 2 次节奏呼吸（日常/温情场景在战斗/冲突之间）
- 高潮逐步升级：{{个人冲突 → 门派斗争 → 正邪大战 → 天地浩劫 / 自定义}}

### 4.2 章级节奏

- 每章结尾必须有钩子（悬念/情感/信息/动作）
- 情感高潮场景用"慢镜头"处理
- 句式长短随情绪变化——紧张=短句、平静=中长句、悲伤=断句

### 4.3 字数底线

- 每章中文字符 ≥ 2000（网文最低标准）
- 破折号 `——` ≤ 15 处/章
- 数字用中文写法，阿拉伯数字仅允许年份/数据

## 五、禁止事项（零容忍）

以下规则来自已验证有效的写作经验，所有小说通用：

1. **禁止"不是X，是Y"句式** — 一章零容忍
2. **禁止金句收尾** — 让事实自己站着，不替读者总结
3. **禁止同义重击句式** — 不说两遍同一个意思
4. **禁止没头没脑的台词** — 对话必须有完整语义
5. **禁止无连接词的断裂叙述** — 句子间必须有词汇连接
6. **禁止情绪概括词直给** — 喜悦/愤怒/悲伤/恐惧/激动/感动/兴奋/紧张/焦虑/失落/欣慰/感慨 一律禁止直接出现
7. **禁止角色替作者传话** — 角色不能说"作者想让读者知道但角色没理由说"的信息
8. **关联内容禁止句号切割** — 同一事件的连续步骤用逗号串起来
9. **禁止摄影机视角** — 叙述必须从主角的感知出发，不是中立旁观
10. **禁止重复描写同一特征** — 全书同一个标志性动作/身体特征 ≤ 3 次

## 六、检查清单

### 写前（每次写新章前必过）

- [ ] 对照世界观看有没有违反规则
- [ ] 出场角色的当前知识边界确认（实体认知越界检查）
- [ ] 读上一章最后 3 段——确认章首从章末的下一刻开始
- [ ] 确认本章在大纲中的位置和情感基调
- [ ] 回顾 `shared/references/ai_patterns.md` 51 条禁止模式

### 写后（每次写完必查）

- [ ] 字数 ≥ 2000（`[一-鿿]` 正则）
- [ ] 破折号 ≤ 15
- [ ] AI 标记扫描（51 条）
- [ ] POV 约束（每段问"主角怎么知道的"）
- [ ] 情绪概括词扫描
- [ ] 不是X是Y 扫描
- [ ] 跨章接缝（章首 vs 章末一致性）
- [ ] 对话真实性（出声朗读）
- [ ] 信息量（逐句删——删了不影响理解就是废话）
- [ ] 错别字（逐句出声默读）
