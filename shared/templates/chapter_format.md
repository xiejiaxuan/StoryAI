# 章节输出格式规范

## 章节标题
```
## 第{{N}}章 {{章节标题}}
```

## 正文格式要求

### 段落
- 每个段落 150-800 字为宜
- 段落间空一行
- 场景切换用 `***` 分隔线

### 对话
- 对话用中文双引号：「」或 ""
- 每段对话原则上不超过 200 字
- 对话后原则上跟动作/神态描写
- 避免连续 5 句以上纯对话

### 叙述视角
- 统一视角：一个章节内不超过一个 POV 角色
- 避免上帝视角突然插入内心独白

### 数字与标点
- 纯中文数字：一、二、三十、一百零八
- 严禁阿拉伯数字（0-9）
- 严禁英文单词（专有名词除外，需首章定义）
- 中文标点：。！？，、；：""''（）【】《》

### 禁用词
- AI 标记词：暗思涌起、心理描写、环境描写、动作描写、命运的齿轮
- 模板化结尾：未完待续、真正的危机才刚刚开始、更大的风暴即将来临

## 章节结束标记
```
<!-- chapter_end -->
```
