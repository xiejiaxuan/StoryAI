# 第 39 章 邀请函

莫里斯的球探报告在 NBA 圈子里传得比卡特预期的快。

三天后卡特接到了第一个 NBA 总经理的私人电话，不是球探，是总经理。他接电话时正坐在办公室里整理联合试训的材料，听到对方的自我介绍后把口香糖从左边换到右边，顺手把手机从耳边拿下来看了一眼屏幕，确认这个号码是真的。接下来四十八小时内他收到了八份联合试训邀请的确认邮件，以及十几个请求私下试训的邀约。每一封邮件的措辞都差不多，"我们对 Jason Blake 非常感兴趣"，但"非常"这个词在不同邮件里的排版不一样，有的加粗，有的下面画了线，有的直接写在了邮件标题里。

卡特把所有邀请按日期排好贴在白板上。热火，凯尔特人，勇士，猛龙，尼克斯，公牛，马刺。他把口香糖嚼了好一会儿，然后拿起一支紫色记号笔在最下面加了最后一行：**湖人**。

"你的首选。"卡特在"湖人"旁边画了一个圈。

科比看着白板上那个紫色的圈。湖人。他的球队。他穿了二十年的球衣，拿了五次冠军，在斯台普斯中心地板上跳起来过不知道多少次，踩下去时认识脚下每一块木纹的软硬。现在他们问一个来自 MEAC 的二十二岁后卫能不能来试训。他应该感到兴奋，但他更多的是沉默。因为他知道，从这间办公室到那件紫金球衣之间的距离不只是一个试训。是整个联盟对他的怀疑。MEAC 球员。传球为先。不投篮。会在 NBA 级别被防住。这些标签贴在每一个从不知名学校出来的球员身上，不管他们在全国锦标赛上拿了多少分。

科比站在白板前看着那些名字：热火，凯尔特人，勇士，猛龙，尼克斯，公牛，马刺。每一支都是一扇门。但他在找的不是门，是那扇他一直站在门口、从来没进去过的门。湖人。紫色的圈。卡特在圈旁边又画了一个小圈，没有解释，但科比知道那是什么：不确定。湖人还没有正式发出邀请。他们有高顺位签吗？他们会为一个 MEAC 后卫付出代价吗？这些问题在巴克莱中心选秀夜之前都不会有答案。

"去芝加哥之前我有六周。"科比把训练日志翻到新的一页，在顶端写了"选秀前六周"。然后把六周分解成了每一天的训练模块。

第一周：力量 + 速度 + 核心稳定性。第二周：投篮精度 + 出手速度 + 控球进阶。第三周：防守脚步 + 对抗强度 + 一对一面框和背身。第四至六周：对抗赛模拟 + 恢复 + 心理准备。每一周都有精确到每天的训练内容，从早上四点半到晚上八点，每个小时都用记号笔框住了。卡特看了这份计划之后把口香糖从左边换到右边，然后又换回来。

"你确定你能撑下来吗。这比 NCAA 赛季中任何一周的强度都高。"

"我做了二十年类似的训练计划。"科比说出口的瞬间意识到自己说了什么。然后补了一句："我是说，我从小就习惯这样训练。"

卡特没有点破。他只是站起来走到门口。"明天凌晨四点半，不，你应该休息一天。"然后他听到科比说"四点半"之后，用手拍了一下门框，没有回头。"我就知道。"

走廊灯亮了一片。卡特走到走廊尽头，又回头看了一眼办公室门缝底下透出的光。科比还在里面，笔尖在纸上移动。

接下来的六周里科比的生活回到了最简单的节奏。每天凌晨他走进训练馆时天还黑着，走廊声控灯的习惯还没改——从门口到球馆需要亮七盏灯，每一盏都会在他走过去之后暗掉——整个走廊只有他脚下的一块是亮的。他发现自己回到了最熟悉的状态：没有观众，没有媒体，只有球弹地的回声和身体肌肉的反馈。

凌晨四点半到球馆训练到七点，上午力量房练到九点，下午专项技术训练，晚上录像分析。大 D 已经毕业离校了，走之前把自己的护膝留给了科比，上面用记号笔写着"**五度**"。Marcus 去了西班牙试训，每天给科比发一条短信，内容从"这边的防守都是联防"到"我今天在训练里用你教我的那套后脚阅读防住了一个打过西甲的老兵"。

泰瑞克还在学校。他每天凌晨四点半照常来球馆，成了科比六周冲刺训练里最稳定的训练伙伴。他现在不用提醒膝盖弯好，他的膝盖在球到之前自动弯好了。他把手机锁在柜子里的习惯坚持了一整年。TikTok 停更了好几个月。不是因为不能拍，是他没有再找到比训练馆里凌晨的安静更有意思的东西。

六周结束后，科比站上体重计，二百零三磅，比六周前重了八磅。体脂率降到百分之七。垂直弹跳从九十八厘米升到了一百零三厘米。他把这些数字写在训练日志最后一页。然后翻开新的一页，写下一行字。

**芝加哥。联合中心。试训舞台。**

窗外训练馆的灯亮着。泰瑞克已经在里面热身了。

科比把训练日志合上，拿起毛巾搭在肩上。六周前他站上体重计时指针停在了一百九十五磅，今天是一百零三。八磅肌肉，五厘米弹跳，零点几秒的第一步爆发力提升。这些数字在联合试训的体测表上会被记录员用黑色记号笔写在白板上，然后被球探们抄进笔记本。但数字本身不会告诉他们任何事——他们需要在对抗赛中看到一个不到二十岁的后卫在防守端用脚步阅读压制乐透级别的对手，在进攻端用后仰和传球证明全国冠军的三十六分不是因为 MEAC 太弱而是因为他当时不想每场都得三十六分。

他推开训练馆的门。泰瑞克正在做他最拿手的底角三分练习，接球弯膝出手命中，接球弯膝出手命中，重复了十二次一次没丢。他转头看到科比，咧嘴笑了一下——然后继续下一个。不问问题，不抱怨，只是在凌晨和篮球之间做他一直在做的事。科比站到他旁边，拿起一颗球。两个人各自对着各自的篮筐投了一百球——科比在左半场，泰瑞克在右半场——球弹地的回声重叠在一起，在整个球馆里荡来荡去。没人说话。不需要说话。六周之后这间球馆会安静下来，泰瑞克会继续在这里等他下一批队友——他自己会坐在飞往芝加哥的航班上，窗外是渐渐变小、最后缩成一个点的北卡罗来纳。科比抬头看了看墙上的钟：凌晨五点半。太阳在球场东窗外开始发白。他把训练日志放进办公室抽屉里，上面压着莫里斯的球探报告。六周。七十二场训练。然后在联合中心，他会把一个句号变成一个感叹号。
