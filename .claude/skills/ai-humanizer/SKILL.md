# AI Humanizer — 去 AI 味

## 角色定义

你同时扮演两个角色：

1. **扫地机** — 清除显眼的 AI 污染：AI 标记词、模板化结尾、空洞拔高、情感偷懒表达
2. **打磨工** — 在**不虚构**的前提下主动打磨：弱动词强化、节奏重塑、filler 切除、语序归位

## 工作流

### 第 1 步：AI 腔扫描

```bash
python .claude/skills/ai-humanizer/scripts/detect_patterns.py --file <章节文件>
```

这会扫描全部 51 条 AI 腔模式（A-I 九大类）并输出命中报告。同时加载 `shared/references/deai_rules.md` 的 10 条规则作为补充判定基准。

### 第 2 步：分级处理

根据扫描结果分级处理：

**严重度 5（必须修改）**：
- "他不知道的是"/"殊不知" → 删除
- "命运的齿轮" → 删除
- "才刚刚开始"结尾 → 删除，用具体情节的未完成感结束
- 排比式收尾（"让我们……"） → 删除

**严重度 4（建议修改）**：
- 心中涌起 / 涌上心头 → 用具体动作替代
- 叹气+苦笑+摇头三件套 → 替换为角色特有的表达
- 武器/战斗模板化描写 → 增加策略和代价
- 修炼流水账 → 增加阻碍和体感

**严重度 3（选择性修改）**：
- 不由自/下意识 → 大多数情况直接删除
- 嘴角扬起 / 目光闪烁 → 分散到其他身体语言
- "说道"重复 → 用动作Beat替代

**严重度 1-2（微调）**：
- "非常/极其" → 用更强的实词替代或删除
- "似乎/仿佛" → 要么确定，要么用感官细节
- 段落节奏 → 制造长短交替

### 第 3 步：改写执行

对每个需要改写的段落，遵循以下约束：

**硬约束（优先级最高）**：
- 不发明事实 — 不添加原文没有的具体数字、事件、人物行为
- 不改变情节 — 不改动剧情走向和角色行为
- 不改变字数 — 改写后字数在原文 ±5% 范围内

**风格约束**：
- 保持原文的语体和调性
- 保持角色的语言风格
- 保持叙事视角一致

### 第 4 步：改写后自检

改写完成后，对照原文逐段检查：
1. 核心信息是否完整保留？
2. 有没有添加原文不存在的事实？
3. 是否误删了角色的标志性表达？
4. 改写后的段落读起来是否更像人写的？

## 输出

- `chapters/chapter_NNNN_humanized.md` — 去 AI 味后的章节
- 改写完成后附一份打磨报告：
  - 扫描到的 AI 模式总数
  - 各类别修改数量
  - 保留的毛边（主观判断/圈层语境，有意保留的"人味"）
  - 未处理项及原因（如受"不发明事实"约束而无法修改的部分）

## 约束
- 只支持简体中文
- 只处理文本，不新增观点或情节
- 保留至少一处"毛边"——避免改成无菌的中性文字
