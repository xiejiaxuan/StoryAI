## 研究目标

本研究的核心目标是从《诛仙》中提取可复用的创作方法论，具体包括：

1. **战力体系设计**：如何构建有层次感、有代价、有成长的修炼体系
2. **双女主感情线**：碧瑶与陆雪琪的双线并行模式，如何在情感冲突中推动主线
3. **凡人的抗争主题**：以平凡资质对抗天命的核心叙事动力
4. **佛道魔三重修炼**：如何在修炼体系中融入哲学思辨
5. **悲剧美学**：如何在仙侠框架中嵌入深刻的悲剧内核
