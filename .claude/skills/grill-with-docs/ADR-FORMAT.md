# SDR 格式（故事决策记录）

SDR 存放在 `docs/sdr/` 目录下，使用序列编号：`0001-短标题.md`、`0002-短标题.md`。

`docs/sdr/` 目录在需要第一个 SDR 时才创建。

## 模板

```md
# {决策的简短标题}

{1-3 句话：什么背景、做了什么决定、为什么。}
```

就这些。一个 SDR 可以只是一个段落。价值在于记录**做了**什么决定以及**为什么**——不在于填满各个章节。

## 可选章节

只在能增加真正价值时才添加。大多数 SDR 不需要。

- **Status** frontmatter（`proposed | accepted | deprecated | superseded by SDR-NNNN`）— 当决策被重新审视时有用
- **Considered Options** — 只在被拒绝的替代方案值得记住时才写
- **Consequences** — 只在需要指出非显而易见的连锁效应时才写

## 编号

扫描 `docs/sdr/` 找最大的现有编号，加一。

## 何时提供 SDR

以下三个条件必须全部满足：

1. **难以逆转** — 改变决定的成本是显著的（影响多章甚至多卷）
2. **没有上下文会令人困惑** — 未来的读者会看着情节问"为什么作者这样写？"
3. **是真正权衡的结果** — 存在真实的可选方案，你为了特定原因选择了其中一个

如果一个决定容易逆转，跳过——你以后直接改就行了。如果不令人困惑，没人会质疑为什么。如果没有真正的替代方案，除了"作者做了唯一能做的事"之外没什么好记录的。

### 什么样的事情值得 SDR

- **故事结构决策**："主角设定为只重生身体不重生能力""双主角叙事中的 POV 交替规则"
- **角色命运决策**："关键角色 X 在第 Y 卷死亡——为什么必须在这个节点、以这种方式"
- **世界观规则决策**："力量体系的限制条件——为什么选择冷却时间而非消耗法力"
- **叙事技巧决策**："非线性叙事的触发条件和边界"
- **刻意偏离常规的选择**："为什么用第一人称而非第三人称写这一卷""为什么这场关键比赛不写比赛过程"
- **代码/设定中不可见的约束**："禁止写主角的童年闪回——因为要留到第三卷作为最大反转"

### 不属于 SDR 的

- **可逆的小情节调整**：某章的对话改了、一个配角的名字改了——直接改就行
- **明显的选择**：主角赢了关键比赛、反派最终输了——这些不需要解释
- **临时实验**：试试某种写法看效果——试完不合适就改回来
