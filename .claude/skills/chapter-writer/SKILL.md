# Chapter Writer — 章节写作

## 前置准备

写作前自动加载以下上下文（如果存在）：

1. `.storyai/config.json` — 项目配置（书名、类型、主角名、POV 风格）
2. `world_settings.md` — 只加载**与本章相关的规则摘要**（不超过 500 字）
3. `characters.md` — 只加载**本章出场角色**的档案摘要
4. `chapters/briefs/NNNN.md` — 本章写作指令
5. `chapters/chapter_N-1.md` 的末 500 字 — 前一章结尾（用于续写衔接）
6. `consistency_report.md` 的最新警告 — 如果之前有跨章矛盾提示
7. `.storyai/novel-rules.md` — **本小说特定规则，必须逐条过，写的时候每写一段都要在脑子里回想**
8. `shared/references/ai_patterns.md` 的约束摘要 — 51 条禁止模式列表
9. `shared/references/deai_rules.md` 的约束摘要 — 10 条去 AI 化规则 + 四大核心病症

## 写作约束

**核心原则：规则是写的时候用的，不是写完拿来对答案的。每写完一段，脑子里过一遍——**
- 有没有蹦出"不是X，是Y"？（零容忍）
- 句子之间有没有"然后""过了几秒""这时候"等连接词？（不能突然蹦出来）
- 有没有故作高深的短句留白？（"那个回头是为什么？他不知道"这种）
- 有没有概括情绪词直给？（"悲伤""愤怒""恐惧""喜悦"）
- 破折号是不是又当逗号用了？

写作时严格遵守以下约束（作为系统级指令）：

### 必须做
- ✅ 纯中文输出，数字用中文写法（一、二、三十……）
- ✅ 第三人称有限视角，单场景内不切换 POV
- ✅ 长短句交替，段落 150-800 字的节奏变化
- ✅ 对话 + 动作 Beat 交替（不说"XX 说道"，用具体动作替代）
- ✅ 情感通过动作和感官细节展示（show, don't tell）
- ✅ 战斗描写包含策略、代价、心理（不只特效）
- ✅ 修炼/升级有阻碍和体感（不只流程）
- ✅ 忠于写作指令的情节要求
- ✅ **感官密度**：每千字 ≥ 1 触感/温度 + 1 气味 + 1 非视听身体感觉（详见 deai_rules.md 规则 1）
- ✅ **比喻具象化**：禁止概念化比喻，必须用故事世界内的具象喻体（详见 deai_rules.md 规则 6）
- ✅ **逻辑留白**：人物动机保留至少 1 个不可解释的细节（详见 deai_rules.md 规则 4）

### 禁止做
- ❌ 51 条 AI 腔模式（详见 `shared/references/ai_patterns.md`），特别是：
  - 心中涌起 / 内心充满了 / 感到一阵 / 不由得
  - 暗思涌起 / 心理描写 / 命运的齿轮 / 殊不知 / 他不知道的是
  - 嘴角扬起 / 目光闪烁 / 叹了口气 + 苦笑 + 摇头三件套
  - 真正的危机才刚刚开始 / 未完待续 / 更大的风暴即将来临
- ❌ **去 AI 化规则禁止项**（详见 `shared/references/deai_rules.md`）：
  - 情感名词直给（悲伤、愤怒、恐惧、喜悦）——改用动作/生理反应替代
  - "这意味着/这象征着/这让他意识到"——作者下场解释
  - "毕竟/无论如何，生活总要继续/或许，这就是命运吧"——强行升华结尾
  - 对话信息倾泻——每段对话必须有潜台词、打岔或沉默
  - "淡淡道/冷冷道/沉声道/苦笑道"——对话标签模板化
- ❌ 阿拉伯数字 (0-9)
- ❌ 英文单词
- ❌ 上帝视角 POV 漂移
- ❌ "不是X，是Y"句式超过 1 次/章
- ❌ 章节结尾感悟、总结、升华、抒情议论——让故事在动作/画面中收束（deai_rules.md 规则 7）

## 章节长度控制

- 目标字数来自写作指令，默认 8,000-12,000 中文字
- 如果需要超长章（>12,000 字），分 2-3 段生成，每段 ~4,000 字
- 分段生成时，每段末尾提供续写钩子，下一段自然衔接

## 写后拷打（Grill — 必做，排在自检之前）

**章节写完后，立即进行拷打式深度评审。** 这是写后检查的第 0 步，排在 AI 标记快速检测之前。

拷打清单（逐项过，一项不能跳）：
1. **POV 越界**：每一段问"这个信息主角是怎么知道的？"答不出来 = 违规
2. **对话真实性**：出声朗读对话——像真人在说话还是像朗读论文？
3. **场景逻辑**：每个场景的发生地点、时间、人物是否合理？
4. **情感真实性**：角色情绪反应是否与性格/处境一致？有没有概括情绪词直给？
5. **事实准确性**：篮球规则、NBA 时间线、真实人物/事件是否正确？
6. **节奏**：本章内部是否有张弛变化？段落长短是否有节奏？
7. **信息量**：逐句删——删了不影响理解的句子就是废话
8. **跨章接缝**：章首从章末的下一刻开始了吗？时间参照有前章对应吗？
9. **实体认知越界**：每个角色在当前时间点知道什么？
10. **对话主语**：连续从句有没有重复主语（"你...你...你..."）？

拷打中暴露的问题必须当场解决。如果发现大纲级别的问题（情节逻辑漏洞、角色动机矛盾），先回退修改大纲。

详细规则见 `CLAUDE.md` 中"拷打式评审（Grill）强制规则"章节，以及 `grill-with-docs` skill。

## 自检

写完后执行快速 AI 标记检测：

```bash
python .claude/skills/chapter-writer/scripts/ai_detector_quick.py --file chapters/chapter_NNNN.md
```

- Exit code 1（严重）：自动修订后再输出
- Exit code 2（警告）：列出警告项，让用户决定
- Exit code 0（干净）：直接输出

## 输出

- `chapters/chapter_NNNN.md` — 完整章节
- 章节末尾添加 `<!-- chapter_end -->` 标记
