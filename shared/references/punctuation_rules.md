# 中文标点规范

## 标点符号使用标准

### 句末标点
| 符号 | 用法 | 示例 |
|------|------|------|
| 。 | 陈述句结尾 | 林阎推门而入。 |
| ？ | 疑问句结尾 | 你确定？ |
| ！ | 感叹/祈使 | 小心！ |
| …… | 省略/迟疑/沉默 | 他说……算了吧。 |
| —— | 转折/强调/中断 | 她转头一看——是他。 |

### 句中标点
| 符号 | 用法 |
|------|------|
| ， | 一般停顿 |
| 、 | 并列列举（中文特有的顿号） |
| ； | 长句分句间停顿 |
| ： | 引出对话、说明、列举 |

### 引号
| 类型 | 用法 |
|------|------|
| 「」或 "" | 对话引用（建议统一使用一种） |
| 「『』」 | 对话内嵌套引用 |

### 括号
| 类型 | 用法 |
|------|------|
| （） | 补充说明 |
| 【】 | 系统信息、面板提示 |
| 《》 | 书名号 |

## 常见错误

1. **中英标点混用**：句号混用 `。` 和 `.`
2. **引号不配对**：左引号和右引号数目不一致
3. **顿号误用为逗号**：并列列举中用了逗号而非顿号
4. **省略号格式**：应该用 `……`（两个 U+2026），不是 `。。。` 或 `...`
5. **破折号格式**：用 `——`（两个 U+2014），不是 `--` 或 `—`

## 网文特有标点用法

- 系统提示/面板信息使用【】
- 传音入密/心声可使用 『』 括起来
- 功法名称可使用《》书名号
- 大段心理活动可使用 （） 括起来
