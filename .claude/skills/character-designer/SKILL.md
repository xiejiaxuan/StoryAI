# Character Designer — 角色设计

## 工作流

### 第 1 步：确定核心阵容

先确认：
1. **主角数**：单主角/双主角/群像？
2. **核心配角**：最少需要几个支撑角色（一般 3-5 个）？
3. **反派设计**：单一反派/反派阵营/无具体反派（对抗环境/命运）？
4. **角色与世界观匹配**：力量体系、势力归属、社会地位

### 第 2 步：逐角色生成档案

按照 `shared/templates/character_profile.md` 的结构，为每个角色生成完整档案。

**主角设计要点**：
- 必须有缺陷（性格缺陷、能力短板、认知盲区——至少一个）
- 动机必须具体（不是"变强"，而是"变强之后能做什么"）
- 给一个招牌动作/口头禅/习惯（让人记住）

**配角设计要点**：
- 每个配角必须有独立于主角的目标
- 与主角的关系必须是动态的（会变化）
- 不要"工具人"——赋予独立性格

**反派设计要点**：
- 反派必须相信自己是对的
- 不要"纯粹邪恶"——给动机
- 反派的实力必须是真实的威胁

### 第 3 步：构建关系网络

为每对有关系的主要角色定义：

1. **关系类型**：朋友/敌人/家人/恋人/师徒/利益同盟/互相利用
2. **关系动态**：初始 → 发展 → 可能的终点
3. **冲突点**：他们在什么问题上会有分歧？

### 第 4 步：验证

Python 验证：`python .claude/skills/character-designer/scripts/relationship_graph.py characters.md`

自检清单：
- 每个角色都有性格矛盾点吗？
- 有孤立角色（无任何关系）吗？
- 主角的成长空间够大吗？
- 人际关系能撑起全部篇幅吗？

交给用户审批。

### 第 5 步：导出实体

审批通过后，保存到 `.storyai/character_entities.json`。

## 约束
- 角色能力必须在世界观的力量体系范围内
- 中文命名（人名、绰号、功法名）
- 性别比例合理（不仅是男性角色）
- 每个角色的"语言风格"要具体到词汇选择，不只是"性格冷淡"
