# World Builder — 世界观构建

## 工作流

### 第 1 步：澄清与收敛

如果用户只给了模糊描述（如"我想写一本修仙小说"），先做快速澄清，问：

1. **时代**：古代/现代/近未来/架空？
2. **地理**：单城/大陆/多界/宇宙？
3. **力量体系**：修仙/魔法/异能/科技/无超能力？（如果有，等级怎么划分？）
4. **势力**：有几个主要势力？它们之间什么关系？
5. **历史深度**：有没有影响现在的重大历史事件？
6. **调性**：轻松/严肃/黑暗/热血/幽默？

不要一次问完——根据用户回答追问关键点。如果用户描述已经很详细，跳过这步直接生成。

### 第 2 步：生成世界观文档

按照 `shared/templates/world_settings.md` 的结构生成完整文档。关键原则：

- **具体 > 抽象**：不是"大陆上有几个国家"，而是"青云国占据东部平原，盛产灵石，与西部的赤焰帝国已交战三百年"
- **规则 > 自由**：力量体系必须有明确限制（上限、代价、破绽）
- **冲突内置**：世界设计时就植入矛盾源（资源争夺、种族对立、意识形态冲突）
- **留白**：不要把世界写死，留出剧情发展的空间

### 第 3 步：验证与迭代

生成后进行自检：
- 力量体系有明确上限和代价吗？
- 势力之间有冲突源吗？
- 主角的成长空间存在吗？
- Python 验证：`python .claude/skills/world-builder/scripts/validate_structure.py world_settings.md`

交给用户审批。用户可能要求修改某些部分，迭代直到满意。

### 第 4 步：导出实体

审批通过后，提取关键实体保存到 `.storyai/world_entities.json`：
```json
{
  "format_version": "1.0",
  "locations": {"青云镇": {...}, ...},
  "factions": {"青云宗": {...}, ...},
  "rules": [{"name": "灵力上限", "description": "..."}, ...],
  "events": [{"name": "天劫之战", "time": "三百年前", ...}, ...]
}
```

## 约束
- 确保与世界规则表（可行/不可行）一致
- 力量体系不能有"无限升级"——必须有瓶颈
- 所有地名、人名、组织名统一中文命名
