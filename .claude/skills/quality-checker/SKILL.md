# Quality Checker — 小说 33 维质量审核

## 快速检查（5 项核心）

```bash
python .claude/skills/quality-checker/scripts/quality_check.py --file <章节文件> --quick
```

检查：字数达标、中文纯度、AI 标记词、模板化结尾、段落长度。

## 全量审核（33 维度）

```bash
python .claude/skills/quality-checker/scripts/quality_check.py --file <章节文件> --full
# 含跨章检查
python .claude/skills/quality-checker/scripts/quality_check.py --file <章节文件> --full --prev <前章文件>
# 批量检查
python .claude/skills/quality-checker/scripts/quality_check.py --dir chapters/ --full
```

## 5 层审核体系

### 第一层：基础指标（5 项）
1. 字数达标（≥8,000 字）
2. 中文纯度（>95% 汉字）
3. AI 标记词（0 个）
4. 模板化结尾（0 个）
5. 段落长度合理（最长 < 3,000 字）

### 第二层：文风与结构（8 项）
6. 句子重复率（<10%）
7. 对话比例（25-55%）
8. 标点密度（每百字 25-65 个）
9. 段落节奏变化（变异系数 0.3-1.5）
10. 句长合理（均值 8-25 字）
11. 场景转换自然（每段 0.3-2.0 次）
12. 情感词密度（千字 2-15）
13. 无高频重复词

### 第三层：内容与大纲（7 项）
14. 情节推进（有新事件/新信息）
15. 主角出现密度（千字 0.5-15 次）
16. 动作词密度（千字 2-10）
17. 内心独白适度（千字 1-8）
18. 场景描写适当（千字 3-20）
19. 冲突张力（千字 5-25）
20. 核心设定提及（千字 > 1）

### 第四层：格式与规范（5 项）
21. 无阿拉伯数字
22. 无英文单词
23. 格式一致（无异常短行）
24. 无特殊字符
25. 字数范围合理（8,000-20,000）

### 第五层：高级分析（8 项）
26. 开头吸引力（≥1 个勾子元素）
27. 结尾完整（末段 ≥ 100 字）
28. 段落长短交替
29. 角色名称一致
30. 词汇丰富度
31. 第三人称一致
32. 场景完整（对话+动作+环境）
33. 跨章衔接检查

## 审核报告解读

审核后，根据 FAIL 项的严重度决定处理方式：

- **第一层有 FAIL** → 必须修订（基础项不达标不可接受）
- **第二层有 FAIL** → 建议修订（文风问题影响阅读体验）
- **第三层有 FAIL** → 对比大纲，确认是否需要修订
- **第四层有 FAIL** → 格式问题，快速修正即可
- **第五层有 FAIL** → 高级问题，非阻断性但建议关注

## 约束
- 只审核不修改——审核结果反馈给用户和 chapter-writer
- 可以单独调用（不经过 orchestrator），也可作为流水线的一部分
- 对于 AI 标记词检测，需要考虑上下文（某些词在特定语境下是正常的，参考 whitelist_terms.md）
