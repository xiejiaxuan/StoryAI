# CONTEXT.md 格式（故事术语表）

## 结构

```md
# {小说名} 术语表

{一两句话描述这本小说的世界和核心冲突。}

## 角色

**科比·布莱恩特（Jason Blake）**：
重生者。2020 年直升机坠毁后，科比的意识穿越到 2025 年的 Jason Blake 体内。拥有 20 年 NBA 生涯的全部记忆和篮球智商，但用的是 Jason 的身体。
_Avoid_：杰森（叙述中）、原主（指代科比时）

**Marcus Thompson**：
温斯顿-塞勒姆州立大学控卫。第一个发现科比"不对劲"的人。绰号"深渊"的赋予者。
_Avoid_：马库斯（中文音译）

## 地点

**温斯顿-塞勒姆州立大学（WSSU）**：
NCAA D1 MEAC 联盟成员。位于北卡罗来纳州温斯顿-塞勒姆市。科比重生后所在的大学。
_Avoid_：W-S州立、温斯顿大学

**斯台普斯中心（Staples Center）**：
湖人队主场球馆。科比在此打了 20 年。注：2021 年已更名为 Crypto.com Arena，但在角色内心和对话中仍称斯台普斯。
_Avoid_：加密网竞技场、Crypto球馆

## 势力与组织

**MEAC（Mid-Eastern Athletic Conference）**：
NCAA D1 的中东部体育联盟，属于实力最弱的 D1 联盟之一。WSSU 所属联盟。

**湖人队（Los Angeles Lakers）**：
NBA 球队。科比唯一效力过的 NBA 球队。2027 年拥有勒布朗·詹姆斯和卢卡·东契奇。

## 规则与设定

**重生机制**：
无系统、无面板、无任务。科比唯一优势 = 20 年比赛记忆 + 训练方法论 + Jason 的天赋身体。
_Avoid_：金手指、系统流、开挂

**MEAC 标签禁用（第 43 章起）**：
全国锦标赛夺冠 + 联合试训体测数据 + 多队试训后，任何人不得再用"MEAC 出身"贬低科比的能力。
_Avoid_：（不要用任何方式暗示"MEAC 球员不行"）

## 时间线关键节点

**2020.1.26**：科比原身死亡（直升机坠毁）
**2025 秋**：科比在 Jason 体内苏醒
**2026-27 赛季**：NCAA 赛季（Jason 的大三学年）
**2027.6**：NBA 选秀
**2027-28 赛季**：目标 NBA 新秀赛季
```

## 规则

- **要有态度。** 当多个词指向同一概念时，选最好的一个，其余列在 `_Avoid_` 下。
- **定义要紧凑。** 最多一两句话。定义它**是**什么，不是它做了什么事。
- **只包含这个小说世界特有的术语。** 通用写作概念（POV、对话标签、章节结构）不属于这里，即使这个项目大量使用它们。在添加术语前问自己：这个概念是这个故事世界独有的，还是通用写作概念？只有前者才属于这里。
- **当术语自然聚类时，用子标题分组。** 如果所有术语都属于一个单一的连贯领域，平铺列表也可以。

## 单小说 vs 多小说项目

**单小说（大多数情况）：** 一个 `CONTEXT.md` 在小说目录的 `.storyai/` 下。

**多小说：** 每本小说各自维护自己的 `.storyai/CONTEXT.md`，互不干扰。

本 skill 自动推断适用的结构：
- 如果当前小说目录 `.storyai/CONTEXT.md` 存在，读取它
- 如果不存在，在第一个术语被确认时懒创建
